# HemaTrack Flutter MVP

Aplikasi MVP untuk monitoring visual hemangioma anak dengan baseline photo, ghost overlay, manual marking, timeline, dan report PDF sederhana.

## Cara jalan

```bash
flutter pub get
flutter run
```

## Fitur MVP

- Onboarding disclaimer medis
- Profil anak
- Area hemangioma
- Baseline photo
- Follow-up photo mingguan
- Ghost overlay alignment
- Manual marking framework
- Perbandingan perubahan area
- Timeline perkembangan
- Export PDF stub

## Roadmap lanjutan

### Tahap teknis berikut:
- Integrasi camera package penuh
- Hive persistence final
- Polygon marking refinement
- Real image storage
- Chart visual analytics
- Reminder mingguan
- Export PDF production-ready
- Cloud sync opsional
- AI-assisted lesion segmentation (future)

## Catatan penting

- Ini bukan alat diagnosis medis.
- Hasil hanya dokumentasi visual untuk membantu pemantauan.
- Konsultasi dokter tetap diperlukan untuk perubahan signifikan.
