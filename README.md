# HemaTrack Flutter MVP

Aplikasi MVP untuk monitoring visual hemangioma anak dengan baseline photo, ghost overlay, manual marking, timeline, dan report PDF sederhana.

## Cara jalan

```bash
flutter pub get
flutter run
```

## Catatan

- Ini starter project MVP, bukan medical device.
- Measurement berbasis marking manual user dan area relatif, bukan diagnosis medis.
- Kamera memerlukan testing di device fisik Android/iOS.
