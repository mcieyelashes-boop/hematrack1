# HemaTrack Development Guide

## Run locally

```bash
flutter pub get
flutter run
```

## Recommended next steps

### Immediate
- Connect baseline capture to local persistence
- Store baseline image path
- Load baseline image into follow-up overlay
- Finalize manual marking coordinate capture

### Testing
- Use real Android/iOS device
- Camera permissions required
- Validate weekly comparison workflow

### Release prep
- Add icons / splash screen
- Complete PDF export
- Notification permissions
- QA baseline alignment

## Medical note
This app is for visual monitoring only and must not present diagnostic conclusions.
