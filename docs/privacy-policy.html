🏥 Kebijakan Privasi

HemaTrack — Monitoring Visual Hemangioma Anak

✅ Ringkasan: HemaTrack beroperasi sepenuhnya offline. Semua foto dan data tersimpan hanya di perangkat Anda. Kami tidak mengumpulkan, mengirim, atau menjual data apapun.

Terakhir diperbarui: 1 Juni 2025

1. Pendahuluan

HemaTrack ("Aplikasi") adalah aplikasi monitoring visual hemangioma anak yang beroperasi sepenuhnya secara offline di perangkat Anda. Kebijakan privasi ini menjelaskan bagaimana kami menangani informasi Anda.

2. Data yang Dikumpulkan

HemaTrack menyimpan data berikut HANYA di perangkat Anda:

  • Profil anak (nama, tanggal lahir)
  • Foto hemangioma (baseline dan follow-up)
  • Catatan area hemangioma dan lokasi tubuh
  • Data tren ukuran relatif

Tidak ada data yang dikirim ke server kami atau pihak ketiga.

3. Penyimpanan Data

Seluruh data disimpan secara lokal di direktori dokumen aplikasi pada perangkat Anda. Data tidak tersinkronisasi ke cloud dan tidak dapat diakses oleh kami atau pihak lain.

⚠️ Penting: Menghapus aplikasi akan menghapus semua data secara permanen. Kami menyarankan untuk melakukan backup foto secara manual ke penyimpanan eksternal.

4. Izin yang Diperlukan

  • Kamera: Untuk mengambil foto baseline dan follow-up hemangioma. Izin kamera hanya aktif saat layar kamera terbuka.
  • Notifikasi: Untuk pengingat follow-up mingguan (opsional). Dapat dinonaktifkan kapan saja.

5. Disclaimer Medis

HemaTrack adalah alat bantu dokumentasi visual, bukan alat diagnostik medis. Informasi dalam aplikasi ini tidak menggantikan konsultasi dengan dokter spesialis. Selalu konsultasikan kondisi anak Anda kepada dokter yang berwenang.

6. Perlindungan Data Anak

Aplikasi ini dirancang untuk digunakan oleh orang tua atau wali dalam memantau kondisi medis anak. Orang tua/wali bertanggung jawab atas penggunaan aplikasi dan keamanan data anak. Kami tidak mengumpulkan data apapun dari anak-anak secara langsung.

7. Layanan Pihak Ketiga

HemaTrack tidak mengintegrasikan layanan pihak ketiga seperti analitik, iklan, atau media sosial. Tidak ada SDK tracking atau advertising yang digunakan.

8. Perubahan Kebijakan

Kami dapat memperbarui kebijakan privasi ini sewaktu-waktu. Perubahan signifikan akan diberitahukan melalui pembaruan aplikasi. Versi terbaru selalu tersedia di halaman ini.
